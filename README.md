# PsicoVirlene · Apoio à Anamnese (DSM-5)

Ferramenta de apoio clínico para a psicóloga Virlene Torres. Organiza as observações da entrevista e levanta hipóteses a investigar, com base nos critérios do DSM-5.

**Não emite diagnóstico.** A conclusão é sempre da profissional.

## Como usar

1. **Paciente**: iniciais, idade, data e queixa principal.
2. **Triagem**: 16 perguntas por área (Sim / Talvez / Não). Inclui alerta de risco.
3. **Critérios**: checagem detalhada só das hipóteses abertas na triagem.
4. **Resultado**: hipóteses ordenadas, o que falta confirmar e relatório pronto para copiar ou imprimir.

## Hipóteses cobertas (19)

Depressivo maior, distimia, bipolar I, bipolar II, ansiedade generalizada, pânico, ansiedade social, TOC, TEPT, TDAH, TEA, borderline, uso de álcool, insônia, anorexia, bulimia, compulsão alimentar, adaptação e sintomas somáticos.

## Privacidade

- Arquivo único (`index.html`), sem servidor.
- Nada é salvo nem enviado: ao fechar a página, os dados somem.

## Sobre os critérios

Os critérios estão **resumidos com palavras próprias**, com a página do DSM-5 (Artmed, 2014) para conferência no manual. O texto do manual não está incluído neste repositório.
